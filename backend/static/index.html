Analysis Pipeline

1
Parse PCAP
Scapy reads every packet. Extracts 35+ features including DNS, HTTP, TCP flags, flow keys, IAT, payload ratio.
2
Clean & Engineer
Deduplicate, clip outlier values, compute log transforms, SYN-no-ACK flag, rolling IAT std for ML input.
3

Traffic rate, protocol share, top IPs/ports/pairs, TCP flags, DNS stats, flow summary, private/public split.
4
ML Ensemble
Isolation Forest (n=200) + LOF (k=20) on 35 features. Dynamic contamination. OR-vote labelling for high recall.
